🎯 개발 입문 필수 개념

연수2(퀴즈 게임)와 연수3(AI 시뮬레이터)를 통해 배우는 프로그래밍의 핵심

📚 1부: 프로그래밍이란 뭘까?

💡 가장 쉬운 설명

프로그래밍 = 컴퓨터에게 명령을 내리는 것

예시: 엄마한테 "밥 먹어" 라고 말하는 것처럼, 컴퓨터한테도 "화면에 메뉴를 출력해" "사용자가 입력한 숫자를 받아" "그 숫자가 맞는지 비교해" 이런 식으로 차례대로 명령합니다.

차이점: 엄마는 "대충 무슨 뜻인지" 알아들을 수 있지만, 컴퓨터는 정확한 명령어만 이해합니다.

❌ 컴퓨터가 못 알아듣는 말

"메뉴를 예쁘게 만들어" "사용자 입력을 받아" "뭔가를 계산해"

너무 모호해요!

✅ 컴퓨터가 알아듣는 말

print("1. 풀이하기") x = int(input()) if x == 2: print("정답!")

구체적이고 명확해요!

🧩 2부: 연수2 - 퀴즈 게임에서 배운 것

🎮 연수2: 사용자가 풀 수 있는 퀴즈 게임

당신이 만든 것: 사용자가 터미널에서 선택지를 고르고 점수를 받는 프로그램

💾 핵심 개념 1: 데이터를 저장한다 (파일에 보관)

왜 필요할까? 프로그램을 종료하고 다시 켜도 "내가 푼 퀴즈" 와 "최고 점수"를 기억해야죠. 메모리는 프로그램을 끄면 사라지니까, 파일에 저장해야 합니다.
1
사용자가 퀴즈를 풀고 점수를 얻음
2
그 데이터를 파일(state.json)에 기록
3
내일 다시 프로그램을 열 때, 파일에서 불러옴

파일 형식: JSON은 뭘까?

{ "quizzes": [ { "question": "pwd는 뭔가?", "choices": ["ls", "pwd", "cd", "mkdir"], "answer": 2 } ], "best_score": 80 }

JSON = 사람이 쉽게 읽을 수 있고, 컴퓨터도 쉽게 읽고 쓸 수 있는 형식입니다. 중괄호 { } 와 쌍따옴표 " " 를 꼭 맞춰야 해요.

💾 핵심 개념 2: 프로그램을 구조화한다 (클래스 & 메서드)

왜 필요할까? 프로그램이 복잡해질수록 "어떤 코드가 뭘 하는지" 헷갈립니다. 그래서 역할별로 나눕니다.

❌ 엉망인 코드

# 1000줄의 코드가 # 뒤죽박죽 # 어디서부터 읽어야 # 할지 모르겠고 # 고칠 땐 어디를 # 고쳐야 할지 # 모른다...

✅ 깔끔한 코드

class Quiz: def display() def check() class QuizGame: def play() def add_quiz() def save()

Quiz 클래스 = "한 개의 문제"를 관리

  • 문제 (question)
  • 선택지들 (choices)
  • 정답 (answer)
  • 메서드: 문제를 화면에 보여주기, 사용자 답이 맞는지 확인하기

QuizGame 클래스 = "게임 전체"를 관리

  • 퀴즈 목록 (여러 개의 Quiz 객체)
  • 최고 점수
  • 메서드: 메뉴 보여주기, 풀이하기, 추가하기, 저장하기, 불러오기
핵심: 객체지향 = 현실처럼 프로그램을 구성
현실에서 "게임" 하면 여러 "문제들"이 있고, 각 문제는 자신의 정답을 갖고 있죠. 프로그램도 그렇게 만드는 거예요!

💾 핵심 개념 3: 오류를 견딘다 (예외 처리)

왜 필요할까? 사용자가 "abc"를 입력하거나, 파일이 없거나, 프로그램 중간에 Ctrl+C를 눌 수도 있어요. 그럴 때도 프로그램이 멈추지 않아야 합니다.
try: answer = int(input("1-4 중 고르세요: ")) except ValueError: print("숫자를 입력해주세요!") # 다시 입력받기

try = "이 코드를 실행해봐"
except = "만약 오류 나면 이걸 대신 실행해"

🧠 3부: 연수3 - AI는 어떻게 생각할까?

🤖 AI도 단순한 수학을 한다

AI가 "똑똑해 보이지만", 사실은 엄청 많은 숫자를 더하고 곱하는 것일 뿐입니다.

🎯 핵심 개념 1: 필터(Filter)란?

필터 = 패턴을 찾기 위한 "기준이 되는 모양"

십자가 필터를 보자

0 1 0 1 1 1 0 1 0

이건 "십자가 모양"을 나타내는 2차원 배열(표)입니다. 1은 "색칠된 부분", 0은 "비어있는 부분"이에요.

이 필터를 사용하는 목적

"내 앞에 보이는 그림이 십자가 모양인지, X 모양인지 판별하고 싶다!"

그럼 십자가 필터와 X 필터를 만들어서, 입력된 그림과 비교하면 돼요.

🧮 핵심 개념 2: MAC 연산 = 얼마나 비슷한지 계산

MAC (Multiply-Accumulate) = 곱하고 (Multiply) 누적해서 더하기 (Accumulate)

예시: 십자가 모양 찾기

십자가 필터:

0 1 0 1 1 1 0 1 0

입력된 그림 (십자가를 그린 거):

0 1 0 1 1 1 0 1 0

계산 방법:

위치필터입력곱하기
왼쪽 위000 × 0 = 0
위111 × 1 = 1
오른쪽 위000 × 0 = 0
왼쪽111 × 1 = 1
중앙111 × 1 = 1
오른쪽111 × 1 = 1
왼쪽 아래000 × 0 = 0
아래111 × 1 = 1
오른쪽 아래000 × 0 = 0

모두 더하기: 0 + 1 + 0 + 1 + 1 + 1 + 0 + 1 + 0 = 5점

✅ 점수가 높으면 "십자가 맞다!"

만약 X 필터라면?

1 0 1 0 1 0 1 0 1

같은 십자가 그림(0 1 0 / 1 1 1 / 0 1 0)과 X 필터를 비교하면:

점수 = 1 × 0 + 0 × 1 + 1 × 0 + ... = 1점

❌ 점수가 낮으면 "X가 아니네!"

⚡ 핵심 개념 3: 크기가 커질수록 계산이 복잡해진다

O(N²) = 크기의 제곱만큼 계산량이 는다
크기곱셈 횟수예상 시간
3×39번매우 빠름 ⚡
5×525번빠름 ⚡
13×13169번중간 🔸
25×25625번상대적으로 느림 🐢

📊 패턴: 크기가 2배 → 계산량은 4배

현실에서는: 실제 AI는 수백×수백 크기의 필터로 고화질 사진 한 장을 분석합니다. 이건 엄청난 계산이 필요해서, 일반 CPU로는 너무 느려요. 그래서 GPU나 NPU 같은 "계산 전용 칩"이 필요한 거예요!

🎯 5부: 비전공자가 알아야 할 것

❌ "프로그래밍 = 외우기"는 틀렸어요

프로그래밍은 "문제를 풀기 위한 논리적 사고"예요.

"입력 → 처리 → 출력" 이 흐름만 이해하면, 세부 문법은 나중에 배워도 돼요!

✅ 비전공자가 프로그래밍 할 때의 장점

  • 단순함: "정답은 뭔가?" 같은 고민 없어요. 코드가 하는 일이 전부예요.
  • 의심: "컴퓨터가 정말 이렇게 할까?"라는 의심이 도움 돼요. 테스트를 많이 하게 거든요.
  • 다양성: 전공자는 "이렇게 하는 게 정석"이라고 생각하지만, 당신은 새로운 각도로 접근할 수 있어요.

📖 외워야 할 단어들 (정확히 알아야 해요)

  • 변수 = 값을 담는 상자
  • 함수 = "이 코드 조각을 필요할 때마다 실행해" 라고 등록해두기
  • 클래스 = 함수들을 모아서 하나의 "객체"를 만들기
  • 배열 = 데이터를 순서대로 나열한 것
  • 딕셔너리 = 데이터를 "이름: 값" 형태로 보관
  • 반복문 = 같은 작업을 여러 번 반복
  • 조건문 = "만약 ~라면" 으로 분기하기
