# 실행 검증 결과

명령: `python3 -m unittest discover -s tests -v`

환경: Python 3.14.4 / Linux WSL2. 임시 폴더에서 실행했으며 실제 저장 파일은 수정하지 않았다.

실행 결과:

```text

OK
```

권한 오류는 `unittest.mock`으로 재현했고 실제 사용자 파일 권한은 변경하지 않았다. SIGINT 검증은 POSIX 환경의 결과이며 Windows 키 입력 처리는 이 환경에서 검증하지 않았다. 저장 중 전원 차단·강제 종료·동시 실행 충돌은 현재 보장 범위 밖이다. 성능은 [performance.md](performance.md)에 별도로 기록한다.
